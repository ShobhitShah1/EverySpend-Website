# EverySpend branding

Open /branding/index.html for the mascot studio, /branding/brand-assets.html for store graphics and the splash mascot, /branding/charts.html for charts, and /branding/prototypes.html for earlier concepts.

All full-resolution artwork and earlier variants live in public/branding/assets. The mobile repository keeps only its current native icon/splash inputs and eight compact screen mascots. No mobile build depends on this website checkout. Relative asset URLs work with the configured GitHub Pages base path.
